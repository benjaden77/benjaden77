## A-Share High-Frequency Factor Research

Research into price deviations, order-flow imbalance, and short-term return prediction using minute-level market and order-book data. Covers data cleaning, factor construction, risk neutralization, and out-of-sample validation.

**Technologies:** Python, Pandas, NumPy, DAI SQL

## IMU Sensor Setup and Orientation Estimation

Uses the LSM9DS1 nine-axis sensor and nRF52 platform for I²C data acquisition, sensor calibration, low-pass filtering, Mahony orientation fusion, and BLE wireless transmission.

**Technologies:** C++, nRF52, I²C, BLE, Mahony AHRS

[View project details →](https://tods-notes.netlify.app/projects/imu-sensor-fusion/)
