## 精選專案

### A 股高頻量化因子研究

從分鐘級行情與委託簿資料出發，研究價格偏離、訂單流失衡與短期收益預測，涵蓋資料清理、因子建構、風險中性化及樣本外驗證。

**技術：** Python、Pandas、NumPy、DAI SQL

[查看專案介紹 →](https://tods-notes.netlify.app/projects/quantitative-research/)

### IMU 感測器調試與姿態估測

以 LSM9DS1 九軸感測器和 nRF52 為基礎，實作 I²C 資料採集、感測器校準、低通濾波、Mahony 姿態融合與 BLE 無線傳輸。

**技術：** C++、nRF52、I²C、BLE、Mahony AHRS

[查看專案介紹 →](https://tods-notes.netlify.app/projects/imu-sensor-fusion/)

### 試劑盒檢測系統

串接檢測設備與手機應用，呈現檢測結果並保存歷史資料。主要工作包括視覺化 Demo、App 端資料庫建置及硬體 BLE 連接。

**技術：** BLE、行動應用、資料庫
